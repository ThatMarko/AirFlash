# Improve AirFlash reliability, pairing and diagnostics

Queued receiver work can outlive user intent, missing DNS completions can suppress retries, and terminal engine events can leave pairing input open. This change addresses those paths alongside owned mute recovery, exact input handling and bounded diagnostics.

Base: `Ding-Kyoma:main` at `439de6260e01efbfca528a12cf4d4c1010b3583e`. Head: `ThatMarko:codex/reliability-review` at `a1fce31ef22a44f7c4f789315db9ad407df9f0a7`.

Draft publication is on hold: the owner reports repeated PTP startup failures in preview 6.0.1-rc.1. The source-confirmed scheduling gap is repaired below and corrective 6.0.2-rc.1 is independently package-qualified, but successful owner field retest is still required. Mock/package passes do not override the field report.

The sections below describe the remaining fixes and additions.
