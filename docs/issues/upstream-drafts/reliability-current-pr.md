# Improve AirFlash reliability, pairing and diagnostics

This branch carries the remaining fixes forward onto upstream v0.7.0. Delayed work can no longer displace a newer session, DNS retries have finite logical deadlines, and a terminal engine event closes an open pairing prompt. The changes also improve mute recovery, diagnostics and panel feedback.

Base `Ding-Kyoma:main` at `60e3390`. Head `ThatMarko:codex/upstream-reliability` at `8929881`. The original SDK preflight, settings recovery, PIN/HAP credential changes, native EQ responses and receiver ownership controls already on Main are the foundation for these follow-ups. [Complete diff](https://github.com/ThatMarko/AirFlash/compare/60e3390c8e171a49ba842cd8ccc957d648e3823b...892988193d20a6e2fdc2bd74c919412f21dd2133)

The later capture and engine audit changes drain readable WASAPI packets after a missed wake, preserve upstream ownership recovery and yield on confirmed preemption, and align clock telemetry and capability prediction with playback. Queued remote controls carry the originating live transport's authority. Shutdown closes diagnostics admission without stranding queued writers. Now Playing writes stay ordered, project cached progress on replay, and can clear the native mailbox during standby resume. Retransmit gap telemetry excludes requests for zero packets. [Capture correction](https://github.com/ThatMarko/AirFlash/commit/07587e0fe30882ca7c3348ada0244185e024df54) · [Engine and desktop audit](https://github.com/ThatMarko/AirFlash/commit/a78b723fac05e15a526a797a7134f38978bd543f) · [Follow-up regressions](https://github.com/ThatMarko/AirFlash/commit/d6de3adade3306f72bb74a369e5eeb4352bf96dd)

The first three commits carry the tested v0.7.0 integration. Two follow-ups preserve desktop behavior and PTP and group teardown compatibility identified in the file-by-file audit. ## Review guide

### 1. Build and package boundaries

Reject unbuildable versions before reservation and unsafe package destinations before cleanup. Preserve selected-host precedence, align preview naming and bound release diagnostic children. Fake-operation tests verify ordering, ownership and exit propagation. [Package build](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/scripts/build-package.ps1) · [Release checks](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/tests/test_verify_release.py)

### 2. Session and receiver intent

Capture the snapshot, owner and automatic intent together. Revalidate queued work under serialization, preserve exact manual endpoints and owned settings, and retain active controls through passive discovery gaps and Quit. Keep a visible Stop action if the worker cannot confirm process disposal, and wait for the worker to finish its mute restoration attempt before retrying disposal. During Quit, attempt every cleanup step even if an earlier one fails. Preserve the caller's dispatcher context and keep the owned Stop action available while rejecting new Settings and second-instance activation. Keep a changed default capture endpoint observable when delayed work belongs to a replaced session. Require two distinct usable hosts for a native stereo pair and retain the original advertised endpoints for inspection. Multi-room uses upstream's separate group mode. Per-speaker offsets follow unique receiver identities through reordering. The Sound Glow reset checks session intent so a newer Stop stays authoritative. After ownership loss, the Reconnect action follows receiver availability and returns on rediscovery. Tests cover delayed identity persistence, explicit Stop during admission, alias selection, a manual endpoint changed during a queued Play, retained playback across an adapter change, endpoint recovery, and saved gain whose first guarded application was rejected. Saved volume work is retried with current authority without another save; edits made during application remain pending. [Controller](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.Core/SessionController.cs) · [Lifecycle fixtures](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.Tests/SessionLifecycleTests.cs) · [Saved-gain UI fixtures](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.App/Verification/UiSessionLifecycle.cs) · [Shutdown order and failure coverage](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.Tests/ShellShutdownTests.cs)

### 3. Settings recovery

Reject a null software-group ID through the existing original-byte recovery path. Controls cover repeated loads, BOM recovery and schema-4-to-5 migration. [Settings fixtures](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.Tests/SoftwareGroupSettingsTests.cs)

### 4. DNS lifetime

Separate logical deadlines from native ownership. Bound retries and queued work, ignore obsolete callbacks and retain uncertain helper capacity until exact child exit. Coalesce ordinary queue waits separately from ownership warnings. Report logical stop and actual ownership settlement separately, keeping the existing release result field. [Discovery coordinator](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.App/Services/WindowsDiscovery.cs) · [Resolve fixtures](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.Tests/ResolveProcessTests.cs)

### 5. Pairing and stored passwords

This follows merged PR #25, which normalized PIN input and corrected HAP credential lookup. Treat only initial-open absence as a missing stored password. Read the opened object once with a bound and preserve DPAPI/decoding errors. Validate the complete UTF-8 value and keep one reader while input is open. Join the prompt before reporting a terminal event. Exercise the real authentication selector with injected lookups and exchanges, covering both storage errors and failed exchanges without fallback. [Stored credentials](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/native/airflash-engine/src/credentials.rs) · [Prompt lifecycle fixtures](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.Tests/PairingPromptLifecycleTests.cs) · [Merged PR #25](https://github.com/Ding-Kyoma/AirFlash/pull/25)

### 6. Process-owned IPC faults

Keep the defined JSONL v1 terminal error's detail and nonretryable classification in hello, receiver-capability and application-catalog queries. Preserve the session filters and upstream equalizer preparation behavior. [IPC fixtures](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.Tests/IpcFailureTests.cs)

### 7. Local mute recovery

Journal the exact endpoint and previous bit before muting, under an exclusive owner lease. Keep unresolved or ambiguous records and attempt exact restoration during normal cleanup. Fake endpoints exercise both prior bits, lease contention and persistence failures. [Mute recovery fixtures](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.Tests/MuteRecoveryTests.cs)

### 8. Diagnostics, panel feedback and clock startup

Expose Monitor Copy alongside Export and report optional pre-EQ padded frames and wholly padded pulls once per shared capture pull. Keep retry faults visible until recovery, provide localized notice dismissal, and reserve scrollbar space only when needed. Align the master and receiver volume tracks when the list overflows. Validate PTP Grant message fields, exact peer and target, complete TLV framing and current per-type pending requests. Ignore reserved Grant bits and retain upstream clock readiness and retry cadence. Accept independently reordered Grants and same-identity contract renewal without treating the sender counter as a local request token. A delayed valid Grant can match a later compatible pending request. The serialized replay counter remains zero for compatibility. Record Grant acceptance and rejection categories and subscription send failures in the existing clock diagnostics. Keep using the last validated PTP mapping during the existing grace period if the same clock needs to reacquire. Preserve the upstream ownership guard when the clock expires or recovers during an ownership check. Check parsed receiver ownership signals before any group member sends TEARDOWN. Keep empty capture polls from resetting the silence-probe cooldown and distinguish digital silence from absent capture when deciding whether to reopen. Give Settings navigation and dropdown scrollbars their own columns. Use the same merged receiver model for catalog display and automatic PTP role selection. Start the capture crossfade at the first sample from a reopened stream, including inside a packet. Keep percentile sorting outside the capture lock and share one capture snapshot per reporting interval. [Clock role tests](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.Tests/ReceiverClockRoleTests.cs) · [Capture reopen fix](https://github.com/ThatMarko/AirFlash/commit/181159bcaaa928842f2b0e5dc952ba6751b40700)

Keep bounded counter and discovery histories for diagnosis. Periodic health logging runs off the engine event reader so a slow log sink cannot hold up IPC. During healthy playback, quiet routine resolve warnings when discovery identifies a different receiver. Match exported engine summaries to the request and current playback attempt, check the native epoch when available, and capture the summary together with its counter history. [Diagnostic correlation tests](https://github.com/ThatMarko/AirFlash/blob/892988193d20a6e2fdc2bd74c919412f21dd2133/desktop/AirFlash.Tests/DiagnosticCorrelationTests.cs)

Measure capture age from real captured frames. The extraction percentile omits synthetic padding, and the sender's queue histogram skips empty queues.
