# Improve AirFlash reliability, pairing and diagnostics

Delayed receiver work can outlive user intent, a missing DNS completion can suppress another lookup, and terminal engine events can leave pairing input open. This issue tracks those remaining safeguards and the related recovery, input and diagnostics work against reviewed Main `439de6260e01efbfca528a12cf4d4c1010b3583e`.

Issues #14 and #24 remain the canonical session-intent and authentication reports; the earlier authentication PR #25 remains open. Recent Main integrations already provide SDK preflight, Settings scrolling, MSI payload refresh, configuration recovery, passive transport retention and process IPC/EQ preparation results. The scope below preserves those changes and addresses their remaining consumers or separate follow-ups.

## Scope and acceptance

- [ ] **Package boundaries and host selection.** Reject unsafe cleanup through linked ancestors or contents, agree on stable/preview artifact names, and select the first actual PATH host. Preserve the selected-host SDK resolver, working directory and failure-before-side-effects ordering. Source: [package builder](https://github.com/Ding-Kyoma/AirFlash/blob/439de6260e01efbfca528a12cf4d4c1010b3583e/scripts/build-package.ps1).
- [ ] **Session and receiver intent.** Serialize current owner/intent/eligibility checks with admission and delayed mutations. Reject stale work without undoing accepted saves or consuming automatic candidates; preserve exact manual endpoints and usable active Stop controls, including Connecting and shutdown. A later unrelated settings flush must preserve a newer Pair's owned transport and overrides, including while input is open. Canonical option imports/resets require a unique current transport binding; explicit raw resets, defaults and software membership edits remain intentional. Source: [controller](https://github.com/Ding-Kyoma/AirFlash/blob/439de6260e01efbfca528a12cf4d4c1010b3583e/desktop/AirFlash.Core/SessionController.cs); proposed [settings projection](https://github.com/ThatMarko/AirFlash/blob/6c1e2ef4fd59afb9397fd070df2556fe300eddf2/desktop/AirFlash.Core/SessionSettingsContext.cs#L13).
- [ ] **Settings validation.** Reject null software-group IDs before string operations and use the existing original-byte recovery path. Preserve existing blank-ID rejection, repeated-Load protection, schema-4 migration and unknown fields. Source: [settings](https://github.com/Ding-Kyoma/AirFlash/blob/439de6260e01efbfca528a12cf4d4c1010b3583e/desktop/AirFlash.Core/Settings.cs).
- [ ] **DNS lifetime.** Bound attempts, retry/backoff and unsettled owners; separate advertisement/TTL state from request tokens and epochs. Once a helper may have started, settle ownership only after observing that exact child's exit; proven unstarted owners may settle directly. A timeout, reply or successful-looking cancel is insufficient. Observer and secondary diagnostic-sink failures must not abandon publication or deferred native work. Source: [discovery](https://github.com/Ding-Kyoma/AirFlash/blob/439de6260e01efbfca528a12cf4d4c1010b3583e/desktop/AirFlash.App/Services/WindowsDiscovery.cs); proposed [throwing-sink regressions](https://github.com/ThatMarko/AirFlash/blob/6c1e2ef4fd59afb9397fd070df2556fe300eddf2/desktop/AirFlash.Tests/DiscoveryLifecycleTests.cs#L731).
- [ ] **Authentication.** Preserve credential/password lookup errors and mutually exclusive authentication selection. Only defined initial-open absence selects another eligible path. Share PIN/password enablement and final validation, preserve exact accepted passwords, and cancel/join input on terminal events while retaining one pending reader. Source: [credential reads](https://github.com/Ding-Kyoma/AirFlash/blob/439de6260e01efbfca528a12cf4d4c1010b3583e/native/airflash-engine/src/credentials.rs).
- [ ] **IPC consumers.** Preserve the defined process-owned terminal failure through remaining hello, capabilities and application-catalog consumers, including error detail, nonretryability and cleanup. Retain ordinary session filtering and native EQ preparation semantics. Source: [capability query](https://github.com/Ding-Kyoma/AirFlash/blob/439de6260e01efbfca528a12cf4d4c1010b3583e/desktop/AirFlash.Core/ReceiverCapabilities.cs).
- [ ] **Owned mute recovery.** Persist exact endpoint/prior-bit intent before mutation with an exclusive lease and GUID/generation ownership. Preserve unresolved or ambiguous records, reject mismatched returned endpoint handles, block new muting from overwriting unresolved information, and attempt exact-bit restoration during normal cleanup even after journal failures. Source: [audio service](https://github.com/Ding-Kyoma/AirFlash/blob/439de6260e01efbfca528a12cf4d4c1010b3583e/desktop/AirFlash.App/Services/AudioService.cs).
- [ ] **Diagnostics and capture accounting.** Expose the existing combined diagnostics-copy command from Monitor. Count optional output-rate padded frames and wholly padded pulls before EQ, once per shared pull, while distinguishing missing capture from real/scheduled silence. Remove only unused translation keys after dynamic-consumer review. Source: [capture pulls](https://github.com/Ding-Kyoma/AirFlash/blob/439de6260e01efbfca528a12cf4d4c1010b3583e/native/airflash-engine/src/live.rs).
