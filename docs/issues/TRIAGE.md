## Cross-cutting corrections

- All reports now pin the baseline and separate source evidence, executed observations, future fixture steps, proposed code changes, and acceptance criteria.
- Host-specific `file:///` links, obsolete snippets, and assumed upstream #6/#7 causal mappings are removed. Current reports use portable source links and the audited analysis map.
- JSONL v1, schema 2, DPAPI accessory keys, one authentication method per connection, manual persistence, selected-NIC no-fallback, and exact prior mute bits are treated as constraints on each proposal.
- A missing feature or absent API call is not alone proof of failure. The template/index distinguish enhancements and recovery gaps from defects.
- Passive stream retention, resolve resource ownership, current-session generation guards, and crash mute ownership require different fixes; arbitrary grace periods, token-only removal, and blanket unmute are not substitutes.
- [After discovery](../analysis/after-discovery.md) and [Playback coupling](../analysis/playback-coupling.md) now qualify auto-connect checks as entry checks, not atomic guarantees across awaited persistence. This clarifies source behavior rather than changing runtime policy.
- No receiver firmware behavior, actual egress route, acoustic timing, or physical crash outcome is claimed without a scoped measurement. Per-packet underrun counters and local UDP sends do not establish network health.
